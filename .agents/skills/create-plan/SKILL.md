---
name: create-plan
description: create a plan before implementing a task or feature
---

- make sure nothing is ambigous. ask questions relentlessly until everything becomes clear
- ask your questions one at time
- before writing the plan, provide a summary and ask human for confirmation then proceed to writing the plan
- the plan mus be in $rootRep/docs/plans which must exist
- file name should be 4 digit random number + short description of the task and be a md
- plans must be split to tasks and each one must have [ ] prefix to become a checklist.
- if task is too big split it to multiple phases to be able to implement separately
